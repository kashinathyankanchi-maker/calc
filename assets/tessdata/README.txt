This folder contains Tesseract OCR language data files (.traineddata).
These files are downloaded during CI build (GitHub Actions) and are NOT committed to git.

Files bundled with this app:
- kan.traineddata  (~12 MB) — Kannada script recognition
- eng.traineddata  (~12 MB) — English fallback for Tesseract

Source: https://github.com/tesseract-ocr/tessdata
